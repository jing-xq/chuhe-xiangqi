# 象棋教学软件

面向**零基础新手**的纯网页版象棋学习软件：交互式入门课、1472 课系统教程、
职业分段人机对战、飞刀骗招专项、棋谱保存与复盘分析、AI 私教。
课程数据来自鹏飞象棋内置教学库（9 大分类）。**无需安装、无需联网**（除配置 AI 私教外）。

## 快速开始

双击 `启动教学软件.bat`，自动启动本地服务器并打开浏览器。

或手动：`python tools/serve.py 8000`，浏览器打开 http://127.0.0.1:8000/

> 必须通过本地服务器打开（file:// 无法加载课程与引擎）。建议 Chrome / Edge。

## 六大板块（顶部切换）

### 🌱 新手入门 —— 零基础 10 分钟学会走子
12 节交互课：认识棋盘 → 每个棋子的走法 → 将军与应将 → 将帅照面 → 胜负规则 → 认识记谱法。
边讲边练：在棋盘上动手走，走错会告诉你是哪条规则（马腿/象眼/炮架/九宫/照面）。

### 📖 学棋课程 —— 1472 课系统教程
- 9 大分类：基本杀法 / 实用残局100 / 子力定式 / 中局妙手300 / 全局兵法 / 江湖排局 / 现代布局评注 / 橘中秘评注 / 布局陷阱
- **讲棋模式**：逐步演示、变着对照、评注阅读、自动播放、音效、任意着法跳转、棋盘可翻转
- **练习模式**：猜下一手，走错重试，引擎给提示，自动记录完成度

### 🗡️ 飞刀骗招 —— 布局陷阱专项
源自「布局陷阱100局精选」，**引擎自动分类**并**拆解教学**：
- **飞刀**：对方上当大亏；即便识破不上当，自己也基本不亏（可放心用）
- **骗招**：对方上当大亏；但识破后自己大亏（高风险，慎用）
- 每局四步拆解：**铺垫讲棋**（带原谱评注，可自动播放）→ **陷阱讲解**（生成讲解词：
  关键着、对方随手应的损失、引擎推荐正解）→ **试走陷阱着**（可提示可显错）→
  **上当线/识破线对照**（走完惩罚谱着后，演示对方识破的变化并实时引擎评估）

### ⚔️ 人机对弈 —— 职业分段八档
| 对手 | 风格 |
|---|---|
| 学前 | 随机走子，人生第一盘 |
| 业1~业9 | 逐级变强：从业余初学到准专业，温度抽样控制失误率 |
| 大师 / 特大 | 几乎不走坏棋 / 引擎全力 |

每档附棋风描述与历史交手战绩；执红/执黑、悔棋、认输、求和、
形势条（可折叠）、历史着法回看、棋盘可翻转。

### 🗂️ 我的棋谱 —— 保存、导入与复盘分析
- 对局自动入库；**支持导入外部棋谱**：粘贴文本或选择文件（.txt/.pgn 等，
  中文记谱如「炮二平五 炮8平5」或坐标如「h2e2 b7e7」均可，UTF-8/GBK 自动识别，
  兼容全角数字与繁体棋子字）
- 一键分析：逐着评分、问题着列表（欠佳/失误/漏着，含损分）、形势曲线图、点击跳转复盘
- 查看器支持 **◀ ▶ 逐步翻步**（也可按 ← → 键）、点击任意着法跳转、导出文本
- **已讲解棋谱**（第二标签）：私教点评后点「💾 存入」即可归档——私教自动给棋谱**取名**、
  **打价值评分**（列表左侧分数徽标：≥80 金 / ≥60 绿 / ≥40 黄）并生成**六维评分**
  （开局/中局/残局/进攻/防守/稳定，紧凑雷达图，讲解为主）。点进去是完整复盘：棋盘逐步翻步（◀▶ 在棋盘下方，
  也可按 ← →）+ 六维雷达图 + 私教讲解原文（Markdown 排版），仍可跑引擎分析与查看形势曲线

### 🤖 象棋私教 —— 你自己的 AI 教练
- 自填任意 OpenAI 兼容 API（默认 DeepSeek：`https://api.deepseek.com`，模型 deepseek-chat），Key 只存浏览器本地
- ⚙️ 设置面板收纳全部配置：模型连接（可测试）、**学员习惯档案**（可折叠、可手动修改，
  也可让私教根据战绩自动总结）、**私教提示词**（自定义人设与规则，留空用默认）
- **参照棋盘**：左侧小棋盘跟随上下文（当前对弈 / 所选棋谱），带 **◀▶ 逐步翻步**（标签显示 第N/M手），
  可翻转；**🧪 自由推导** 可对着棋谱任意推演变化（双方合法着自由走），
  **📤 发给私教** 一键把推演变化发给私教点评，✔ 结束推导回到原局面
- **任意棋谱可选**：上下文不再只有"最近一盘"，下拉列出全部棋谱，点评/问答都针对所选
- **预设问题**一键发送（我这盘输在哪 / 关键转折点 / 我的坏习惯 / 练习计划 / 这局该怎么走），减少打字
- **思考可视**：等待时实时显示"私教思考中… N s"，回复后标注思考用时；重思考模型
  （如 deepseek-reasoner）的推理过程可展开查看
- **Markdown 渲染**：回复的标题/加粗/列表/表格/引用/代码块都会排版显示
- **习惯档案记忆**：每次点评后私教总结你的棋风习惯，后续对话自动带上，越教越懂你
- **引擎配合**：点评/问答自动附带局面评分与引擎推荐着，私教点评言之有据
- 功能：点评最近对局（结合复盘分析数据）、自由问答（可挂当前对弈局面/最近棋谱）、总结习惯
- **💾 存入**：把最近一次讲解归档为「已讲解棋谱」（自动取名 + 评分 + 六维图）

## 技术要点

- 引擎为 fairy-stockfish WASM（多线程 pthread，需 COOP/COEP 跨源隔离，服务器已配好），
  加载官方象棋 NNUE 神经网络（`engine/nnue/xiangqi.nnue`），开局与中局评估可靠
- 引擎会话防护：禁 ponder、每次搜索前 stop、会话归属校验 + 超时兜底，批量分析不串局
- 学习进度、棋谱、习惯档案、飞刀分类均存浏览器 localStorage

## 其他说明

- 换浏览器/清缓存会重置本地数据（进度、棋谱、档案、API Key）
- 引擎不可用的环境（如部分内嵌浏览器）自动降级：对弈仅学前档、无提示/分析/分类
- 教学库 1474 课中 2 课因源棋谱数据有误未转换（B/08闪露/071、F/野马操田）
- 重新生成课程数据：`python tools/build_lessons.py`（读取鹏飞 School.zip）

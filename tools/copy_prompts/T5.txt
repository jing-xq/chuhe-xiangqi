你是棋谱语料工人。输入行是「棋谱导入测试用例」的规格：
- seed：开局体系名（仅用于命名，不必出现在文本里）
- op：这条例子要做的格式污染类型
- movesCn：种子着法（中文记法序列，合法）
- movesCoord：同一序列的坐标记法（h2e2 式，合法）
- expect：期望的解析结果（必须原样写进输出，不许改动）

请按 op 把种子着法写成一段「真实棋谱文本」（text），并起一个贴近真实的对局名（name）。

op 的写法要求（文本里着法必须全部来自 movesCn 或 movesCoord，顺序不变、不增删——truncate 除外）：
- plain：着法用空格分隔排成一行（或两行）
- header：开头加 2~4 行【】局头（如【红方 胡荣华】【黑方 李义庭】【对局 1965 上海邀请赛】，可虚构），着法空格分隔
- round-dot：回合号「1.炮二平五 马8进7 2.马二进三 ……」
- round-dun：回合号用「1、」样式
- round-full：回合号用「1．」样式（全角句点）
- round-bracket：回合号用「（一）（二）」或「（1）（2）」样式
- cn-punct：着法之间用中文标点（，。、）分隔
- blank-lines：每个回合占一行，回合之间留空行
- result-win：末尾追加一个结果词（红胜 / 黑胜 / 和棋 任选其一），前面随意加一个局头
- result-draw：末尾追加「和棋」，且中间某处也出现一次结果词
- result-mid：把结果词插在第 3~6 手之间的正文中，其后还有完整着法
- coord：全部用小写坐标记法（h2e2），空格分隔
- upper-coord：全部用大写坐标记法（H2E2），可带回合号
- fullwidth：黑方着法里的阿拉伯数字全部换成全角（马８进７），红方中文数字照旧
- mixed：局头 + 回合号 + 中文标点 + 空行 + 末尾结果词，全部混上
- truncate：只保留 expect.moves 数量的前几手，格式用 plain
- err-garbage：在第 4 手之后插入一个明显不是着法的词（如「此时双方大打出手」），后续着法照常
- err-illegal：在第 4 手之后插入「卒5平4」（没过河的卒不能平移，必不合法），后续着法照常
- err-nonmove：整段只有对局说明文字，不含任何着法

硬性要求：
- 输出是纯 JSONL：每行一个 JSON 对象 {"id":"…","name":"…","text":"…","expect":{…}}，与输入行一一对应、顺序一致
- expect 原样照抄输入；text 里不得出现 emoji；name 为 2~24 字
- text 内的换行用 \n 写在同一行 JSON 字符串里，不要写成多行 JSON

输出示例：
{"id":"T5-001","name":"1965上海邀请赛 胡荣华对李义庭","text":"炮二平五 马8进7 …","expect":{"moves":20}}
